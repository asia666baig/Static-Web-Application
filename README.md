# TechNova - Static Web Application

A responsive static website developed using HTML5, CSS3 and JavaScript.

## Features

- Responsive navigation
- Hero section
- Services section
- About section
- Contact interaction
- CSS Grid layout
- Responsive design
- Hover effects
- Smooth scrolling

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Actions
- GitHub Pages

## Project Structure

static-web-app/
│
├── .github/
│   └── workflows/
│       └── deploy.yml
│
├── index.html
├── style.css
├── script.js
└── README.md

## Deployment

The website is automatically deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the main branch.
